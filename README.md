# Tool Merge — Minecraft 1.16.5 / Forge

Мод позволяет соединять **два одинаковых инструмента** в один следующего уровня.

| Два инструмента из материала | Один инструмент из материала |
| --- | --- |
| Дерево | Камень |
| Камень | Железо |
| Железо | Алмаз |
| Алмаз | Незерит |

Работает для **мечей, кирок и топоров** — всего 12 рецептов. Например:

- Деревянный меч + деревянный меч → каменный меч.
- Алмазная кирка + алмазная кирка → незеритовая кирка.
- Алмазный топор + алмазный топор → незеритовый топор.

## Как использовать

Помести два одинаковых инструмента в **две отдельные ячейки** сетки крафта.
Расположение не важно; подойдёт и сетка 2×2 в инвентаре, и верстак.
Оба исходных инструмента расходуются, результат — один новый инструмент.
Незеритовые инструменты не имеют следующего уровня. Разные типы или материалы
смешивать нельзя. Золотые инструменты, лопаты, мотыги и броня не включены.
Обычные ванильные рецепты остаются доступными.

**Важно:** прочность результата полная, но чары, имена и другие NBT-данные
исходных инструментов не переносятся. Можно использовать повреждённые инструменты.
Рецепты улучшения могут совпасть с ванильным ремонтом двух инструментов;
Minecraft обычно отдаёт приоритет обычному рецепту перед специальным ремонтом.
При наличии других модов проверь результат в выходной ячейке перед крафтом.
Для ремонта с сохранением материала используй точило или наковальню.

## Сборка

Потребуются **JDK 8** (не только JRE), интернет и доступ к репозиториям
Forge/Maven и дистрибутиву Gradle. Gradle Wrapper уже включён в проект.
Используются Forge **36.2.42** и Gradle **7.3.3**.

Windows (PowerShell):

```powershell
.\gradlew.bat build
```

Linux / macOS:

```sh
./gradlew build
```

Готовый файл после успешной сборки: `build/libs/toolmerge-1.0.0.jar`.
Установи Forge для Minecraft 1.16.5 и положи JAR в папку `mods`.
Для сетевой игры устанавливай мод на сервер и клиент.

Запуск тестового клиента из исходников: `./gradlew runClient` (Windows:
`.\gradlew.bat runClient`).

## Проверка рецептов без Minecraft

```sh
python3 -m unittest discover -s tests -v
```

Тесты проверяют точный набор 12 рецептов, одинаковые ингредиенты,
отсутствие улучшений из незерита и формат пакета ресурсов. Они не заменяют
сборку Forge и проверку в игре.

Ручная проверка в игре: попробуй каждую строку таблицы для всех трёх типов,
переставь ингредиенты в сетке, проверь повреждённые и зачарованные предметы,
затем убедись, что смешанные инструменты и два незеритовых не улучшаются.
Ванильный ремонт незеритовых предметов при этом остаётся возможен.
